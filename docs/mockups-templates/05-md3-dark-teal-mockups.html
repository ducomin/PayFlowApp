Detalhe da Assinatura

Hero card · Info grid · Usage bar · Payment history · Dual actions

Material Design 3 · Design System Notes

Color System

  • Seed: Teal #4DD0E1 · Amber #FFD54F
  • Tokens M3: primary / secondary / tertiary
  • Surface container hierarchy (5 níveis)
  • Dark scheme completo com tonal overlays
  • Error / Success / Warning semânticos

Navegação M3

  • NavigationBar com pill indicator ativo
  • Badge em notificações (M3 Badge)
  • Extended FAB para ação primária
  • CenterAligned TopAppBar com tonal elevation
  • Back navigation e trailing actions

Componentes M3

  • FilterChip com check icon e selected state
  • SegmentedButton (mensal/anual)
  • Filled TextField (label + linha ativa)
  • Card Elevated / Filled / Outlined
  • Switch, LinearProgressIndicator

Jetpack Compose

  • MaterialTheme.colorScheme tokens
  • NavigationBar + NavigationBarItem
  • TopAppBar(CenterAligned)
  • ExtendedFloatingActionButton
  • FilterChip, SegmentedButton
  • LinearProgressIndicator

UX Guidelines

  • Touch target min 48×48dp em todos os itens
  • Contraste WCAG AA+ em todo o texto
  • Skeleton screens para estados de loading
  • Estados: loading · sucesso · vazio · erro
  • Feedback imediato em ações do usuário

Diferencial v3

  • Tema escuro nativo (vs. claro nas v1/v2)
  • Paleta Teal+Amber (vs. Indigo+Cyan)
  • Pill indicator no NavBar (M3 puro)
  • Step indicator no formulário
  • Usage LinearProgressIndicator por card
  • Info grid 2×2 na tela de detalhe
