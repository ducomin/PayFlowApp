# PayFlow - Historias de Usuario por Tela

Este diretorio organiza as historias de usuario do MVP do PayFlow a partir do mockup v3 em Material Design 3, do briefing do projeto e das diretrizes de UX/UI.

## Fonte base

- Mockup principal: `docs/mockups-templates/05-md3-dark-teal-mockups.html`
- Escopo funcional: `docs/brief.md`
- Diretrizes de UX/UI: `docs/prompt-instructions-ai-ux-ui.md`

## Premissas de produto

- O aplicativo tera modo dark nativo como experiencia principal.
- O aplicativo devera oferecer opcao de tema light, com paridade funcional e contraste AA.
- O MVP tera 7 telas principais, aderente ao range exigido no brief.
- A navegacao principal usara NavigationBar com 4 destinos: Home, Historico, Avisos e Perfil.
- A criacao de assinatura usara Extended FAB como CTA primario.

## Padrao utilizado nas historias

- Formato: `Como [perfil], quero [objetivo], para [beneficio]`
- Cada tela contem objetivo, historias, criterios de aceite, regras e observacoes UX/UI.
- Os criterios de aceite consideram componentes Material Design 3 do mockup v3.
